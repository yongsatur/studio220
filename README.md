# Фотостудия STUDIO 220

> Данный сайт является **учебным проектом**, созданным в рамках учебной ознакомительной практики в университете.
> Он не имеет отношения к реально существующей фотостудии. Все материалы, включая названия, контакты и отзывы, используются исключительно в образовательных целях.

---

## О проекте

Сайт был разработан в рамках учебной ознакомительной практики для отработки навыков создания лендингов. 
Контент (тексты, цены, отзывы, контакты) является вымышленным и служит только для демонстрации структуры и дизайна.

Основные цели:

*   Закрепление знаний HTML, CSS и JavaScript;
*   Отработка адаптивной верстки;
*   Создание навигации и структурирование контента;
*   Практика работы с формами и интерактивными элементами;
*   Публикация проекта на GitHub Pages.

## Используемые технологии

*   HTML5;
*   CSS3;
*   JavaScript;
*   GitHub Pages.

## Структура сайта

Сайт состоит из следующих блоков:

*   **Шапка (лого и меню)** — навигация;
*   **Главный экран** — приветственное сообщение, описание организации;
*   **Локации** — описание локаций для съемок;
*   **Наша команда** — профили фотографов;
*   **Прайс-лист** — таблица с услугами;
*   **Отзывы** — примеры отзывов клиентов;
*   **Контакты** — адрес и телефон;
*   **Подвал** — Дополнительная информация.

## Запуск проекта

Так как это статический сайт, для его просмотра достаточно открыть файл `index.html` в любом браузере или перейти по ссылке на [GitHub Pages](https://yongsatur.github.io/studio220/).

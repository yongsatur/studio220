# Сайт для фотостудии STUDIO 220

> Данный сайт является **учебным проектом**, созданным в рамках учебной ознакомительной практики в университете.
> Он не имеет отношения к реально существующей фотостудии. Все материалы, включая названия, контакты и отзывы, используются исключительно в образовательных целях.

## О проекте

Сайт был разработан в рамках учебной ознакомительной практики для отработки навыков создания лендингов. Контент (тексты, цены, отзывы, контакты) является вымышленным и служит только для демонстрации структуры и дизайна.

**Основные цели:**

$`\color{yellow}*`$ Закрепление знаний `HTML`, `CSS` и `JavaScript` ;<br>
$`\color{yellow}*`$ Отработка адаптивной верстки;<br>
$`\color{yellow}*`$ Создание навигации и структурирование контента;<br>
$`\color{yellow}*`$ Практика работы с формами и интерактивными элементами;<br>
$`\color{yellow}*`$ Публикация проекта на `GitHub Pages`.

## Стек технологий

$`\color{yellow}*`$ `HTML5` · `CSS3` · `JavaScript`<br>
$`\color{yellow}*`$ `Bootstrap 4`

## Структура сайта

Сайт состоит из следующих блоков:

$`\color{yellow}*`$ **Шапка (лого и меню)** — навигация;<br>
$`\color{yellow}*`$ **Главный экран** — приветственное сообщение, описание организации;<br>
$`\color{yellow}*`$ **Локации** — описание локаций для съемок;<br>
$`\color{yellow}*`$ **Наша команда** — профили фотографов;<br>
$`\color{yellow}*`$ **Прайс-лист** — таблица с услугами;<br>
$`\color{yellow}*`$ **Отзывы** — примеры отзывов клиентов;<br>
$`\color{yellow}*`$ **Контакты** — адрес и телефон;<br>
$`\color{yellow}*`$ **Подвал** — дополнительная информация.

## Демонстрация

Так как это статический сайт, для его просмотра достаточно открыть файл `index.html` в любом браузере. Или можно перейти по ссылке на [GitHub Pages](https://yongsatur.github.io/studio220/).
